# 境外运价

`rates` 是从 GPS 项目拆出的独立运价工作台，面向内部查价使用。

## 模块

- 卡车运价：按提货地址、站点组、还箱站估算欧洲段卡车距离和费用。
- 铁路运价：按换装口岸、目的站、站编、箱型、运输类型计算俄线铁路报价；无直接报价时走散点和公里模型预测。
- 市场参考：展示可用于解释价格的供应商和市场信号；不直接改写计算结果。

## 本地运行

```powershell
cd C:\Users\12514\Documents\rates
$env:RATES_API_HOST='127.0.0.1'
$env:RATES_API_PORT='8025'
python scripts\rates_api.py
```

前端可通过静态服务访问 `web/index.html`。生产环境统一挂载在 `/rates/`。

## 数据边界

- 已导入的 TC 公共报价和散点报价是铁路计算的主要锚点。
- 预测价格只用于无直接报价组合，需要业务人工复核。
- 卡车 API 可读 SQLite；数据库未初始化时使用内置种子数据。
