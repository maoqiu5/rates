# PRD：境外运价

## 背景

GPS 项目中已有卡车运价和铁路运价能力，但它们属于运价工作台，不应继续混在轨迹查询系统内。新项目 `rates` 独立承载境外运价相关工具，并接入 BrianHub 门户。

## 目标

- 将卡车运价、铁路运价、市场参考拆成独立项目。
- 路由使用 `https://brianhub.net/rates/`。
- 保持静态前端加轻量 API 的部署方式。
- 不影响现有 GPS 服务和导航。

## 第一版范围

- 卡车运价：站点列表、市场参考、距离估算和模型金额。
- 铁路运价：TC 报价锚点、散点预测、路线展示、站名/站编输入提示。
- 市场参考：展示依据，不把非结构化来源直接纳入定价。

## 非目标

- 不生成正式客户报价单。
- 不做 Excel/PDF 导出。
- 不做用户权限细分。
- 不把未校验的市场新闻直接自动改价。

## 成功标准

- `/rates/` 可访问前端。
- `/rates/api/health` 返回正常。
- GPS 项目仍可独立访问和使用。
- 本地烟测通过：`tools/test_rates_frontend.js`、`tools/test_rates_api.py`。
